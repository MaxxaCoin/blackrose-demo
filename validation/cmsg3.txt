docs(tools): correct the install allowlist comment

The comment claimed the allowlist covers "python extras (pkg[extra])". It does
not: [ and ] are not in the character class, so `pip install blackrose[all]` is
rejected. Safe direction to fail, but a comment that overstates its own coverage
is worse than no comment - it invites someone to widen the class to "fix" it.

Verified against 16 injection payloads - $(), backticks, ;, &&, pipe, < and >
redirection, newline, quote, backslash, ${IFS}, NUL and %VAR% - all rejected,
and the legitimate forms (scoped, versioned, tilde/caret, dotted, underscored)
still accepted. Comment now states the real boundary and warns that widening the
class re-opens the hole.
