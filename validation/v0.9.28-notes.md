BlackRose 0.9.28 — Telegram button hub + routing fixes

- Telegram button hub: every command is reachable from inline-keyboard buttons. A categorized hub (/help) plus category boards (/menu <cat>, /fun) replace the 50-line help text dump (the plain list is still served for /help).
- /menu and /fun actually route now — they sat on buttons but answered "Unknown command" when tapped.
- /trust on|off fixed: an off-by-one slice read "t on" from the 6-char "/trust", so the Trust buttons never worked.
- Fun board: the /goal roll rolls the football dice instead of starting the goal engine with objective "roll".
- TokenHarbor added as the openai10 route (https://tokenharbor.ai/v1).
- Connected-routes tray: OmniRoute-class gateways that answer 401/403 on /models now fall back to a chat probe instead of showing "down".

Installed 0.9.27 (and earlier) apps will offer this update automatically.
