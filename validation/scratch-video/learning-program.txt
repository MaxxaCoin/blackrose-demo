BLACKROSE LEARNING PROGRAM (mission roadmap, designed 2026-09-28).
Order: Phase 0 learning core (reasoning, research, tools/plugins/skills,
tool discovery) → Phase 1 computer systems (hardware, CPU, OS, Windows,
Linux, virtualization) → Phase 2 Python mastery → Phase 3 software
engineering + Git/GitHub → then networking, databases, web, cloud,
security, AI/ML, agents, automation. Learning method per topic:
LEARN → RESEARCH → EXPLAIN → PRACTICE → USE A TOOL → EXPERIMENT →
VERIFY → CREATE SKILL → RECORD EXPERIENCE → TEST AGAIN. Every subject
in four dimensions: knowledge, skills, tools, experience. Never claim
knowledge or success without evidence; track uncertainty explicitly.
