BlackRose 0.9.29 — auto-continue + stability

- Auto-continue: when a task exhausts the turn budget, the agent now continues automatically for up to 8 extra passes (bounded, configurable) instead of stopping mid-stream — larger jobs complete in fewer manual steps.
- Continuing is still bounded and Stop still applies, so it never runs away.

Installed 0.9.28 (and earlier) apps will offer this update automatically.
