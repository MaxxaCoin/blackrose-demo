PROBLEMS FOUND (all fixed):
  - PowerShell 5.1 WinRT adapter does not expose PdfPageRenderOptions
    properties ("TargetSize cannot be found") → dropped custom render
    options; default 96-dpi PNG render proved sufficient for OCR.
  - Static [System.WindowsRuntimeSystemExtensions]::AsTask cannot bind for
    IAsyncAction (RenderToStreamAsync) → reflected the non-generic AsTask
    overload (PS_AWAIT_ACTION) and Invoke + Wait() it.
  - Hand-built synthetic PDF (GDI+ JPEG + hand-rolled xref) failed
    LoadFromFileAsync with HRESULT 0x80048018 (my xref offsets were wrong;
    Windows' parser is strict) → switched to Edge headless
    --print-to-pdf of a full-page <img>, a genuinely valid image-only PDF.
  - First ocrPdfFile parser accepted PowerShell error chatter as "OCR text"
    (contaminated chunks in the driver's state) → strict parsing: only text
    between BLACKROSE_PAGE markers counts, error patterns stripped, and
    stale validation scratch state must be purged between runs.
